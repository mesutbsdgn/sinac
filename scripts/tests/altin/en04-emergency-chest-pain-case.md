# Case presentation: chest pain

## 1. Presentation

Patient: Jane Doe, DOB 03/14/1987, MRN 4471823
Complaint: pressure-like left chest pain for 40 minutes.

## 2. Findings

- BP 150/90 mmHg, pulse 98/min, SpO2 96%.
- ECG: ST elevation in leads V2 to V4.
- Troponin I: 0.04 ng/mL (laboratory upper limit 0.03 ng/mL).

## 3. First ten minutes

1. Monitor, IV access, oxygen only if saturation is low.
2. Aspirin 300 mg chewed.
3. Call the catheterisation lab.
4. Consider titrated opioid for pain.

## 4. Discussion

In ST elevation myocardial infarction every minute counts; the door-to-balloon target is 90 minutes.

1. Which vascular territory does this ECG pattern suggest?
2. Why is aspirin chewed?
