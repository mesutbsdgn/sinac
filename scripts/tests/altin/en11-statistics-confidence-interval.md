# Confidence intervals and p-values

## 1. Setup

Two classes took the same test after different teaching methods.

| Group | n | Mean | SD |
|---|---|---|---|
| Method A | 30 | 72.0 | 8.5 |
| Method B | 30 | 66.5 | 9.0 |

## 2. Result

Difference in means: 5.5 points. 95% confidence interval: 1.1 to 9.9. Two-sample t-test: p = 0.01. The interval is wide, so read the size of the effect carefully.

## 3. Interpretation

- The interval excludes 0, so the difference is statistically significant at the 5% level.
- A p-value does not measure the size of the effect.
- Report both the interval and an effect size.

## 4. Self-check

1. What does a 95% interval mean, and what does it not mean?
2. Why is "p = 0.000" not a good way to write a result?
