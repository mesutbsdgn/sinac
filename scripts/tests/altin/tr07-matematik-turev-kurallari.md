# Türev kuralları

## 1. Temel kurallar

- Sabitin türevi 0'dır.
- (x^n)' = n·x^(n-1)
- (f + g)' = f' + g'

## 2. Çarpım kuralı

(f·g)' = f'·g + f·g'

Örnek: f(x) = x² ve g(x) = sin x için
(x² · sin x)' = 2x · sin x + x² · cos x.

## 3. Bileşke kuralı

(f(g(x)))' = f'(g(x)) · g'(x)
