# PSA testi: duyarlılık ve özgüllük

## 1. Klinik durum

Hasta: 67 yaşında erkek, idrar yapmakta zorlanma şikayeti. Serum PSA 4,0 ng/mL bulundu.

PSA düzeyi doz değil, ölçüm sonucudur; birim ng/mL'dir.

## 2. İki-iki tablo

| | Hastalık var | Hastalık yok |
|---|---|---|
| Test pozitif | 90 | 60 |
| Test negatif | 10 | 140 |

## 3. Hesaplar

- Duyarlılık = 90 / (90 + 10) = %90
- Özgüllük = 140 / (140 + 60) = %70
- Pozitif öngörü değeri = 90 / 150 = %60

## 4. Yorum

Bu çalışmada test grupları arasında fark anlamlı bulundu (p < 0,001). Küçük örneklemde anlamlılık kararsız olabilir.
