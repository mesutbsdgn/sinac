# Safe prescribing: decimals

## Why notation matters

Trailing zeros are dangerous: 5.0 mg can be misread as 50 mg.

| Written | Verdict |
|---|---|
| .5 mg | ✗ unsafe |
| 0.5 mg | ✓ safe |

## Ward example

The night order read as follows. Give morphine 2.0 mg IV now, then reassess pain in 15 minutes.
The pharmacist asked for the order to be rewritten.
